01 Full-Stack Systems
Flagship Project

Dockerized Inventory and Workflow Management System

Full-Stack Containerized Production-Ready
Problem

Manual inventory tracking caused delays, no visibility into request status, and no access control between roles. Teams had no centralized system to manage stock and workflow requests.

Approach

Built a full-stack system with role-based access control separating admin and user capabilities, JWT authentication for secure sessions, Prisma ORM for structured data access on PostgreSQL, and complete containerization of both frontend and backend services using Docker Compose.

Impact

Automated workflow request handling, gave admins real-time inventory visibility, and eliminated manual hand-off bottlenecks. The architecture is portable - runs identically in any environment with one command.

React Frontend -> Express API -> Prisma ORM -> PostgreSQL // JWT Auth + RBAC Layer + Docker Compose

Logistics Shipment Management System

Active Build RBAC Backend-Heavy
Problem

Engineering Process

How I Build Projects

01

Start with the real problem

What is actually slow, broken, or missing for users or teams? Turn that into a clear problem statement before touching code.

02

Design before code

Sketch flows, data paths, failure points, and security concerns. Structure the solution before writing any implementation.

03

Automate and observe

Scripts, Docker, CI/CD pipelines for the repetitive work. Logs and visibility so issues are easy to find and fix.

04

Document and version

Everything in Git, README written for someone who has never seen the project, architecture explained clearly.
