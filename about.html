I build secure, production-ready systems with a focus on DevOps, backend engineering, and data-driven workflows.

I'm Garv Gupta, a final-year Computer Science Engineering student at Chandigarh University. My work spans containerized full-stack applications, automation scripts, and data validation pipelines. The common thread: I focus on making systems reliable, scalable, and easy to maintain, not just functional.

I started with cybersecurity and Linux, which gave me a systems-first mindset. That foundation shaped how I think about backend engineering. I don't just write APIs, I think about how they'll fail, who should access what, and how they'll be deployed.

My recent work includes a fully dockerized inventory and workflow system with RBAC and JWT authentication, an asset data validation pipeline that catches errors at ingestion, and CI/CD workflows that treat every commit as a deployable artifact.

I focus on building systems that are secure, scalable, and production-ready. Not academic projects. Systems that work the same way in any environment and can be handed to another engineer without confusion.

My long-term goal is to work as a DevOps or backend engineer on teams that care about deployment quality, observability, and operational resilience.

Systems-First Thinking

Linux, networking, and low-level troubleshooting are second nature. I understand what's happening below the application layer.

Security-Aware by Default

Auth, access control, and hardening are built in from the start, not added later. I learned security before I learned to build.

Automation Over Manual Work

If something is done more than twice, it gets scripted. Deployments, user management, validation, monitoring.

Documentation as a Standard

Every project gets a README that explains how to run it from scratch. Undocumented systems are broken systems.
